# Resenha brand delivery

The approved Resenha V2 mark is the single source of truth. Store, product and
press exports must preserve its geometry.

## App icon

`app-icon/` contains every macOS AppIcon slot:

| Points | Scale | Pixels | File |
|---:|:---:|---:|---|
| 16 | 1x | 16 | `resenha-app-icon-16.png` |
| 16 | 2x | 32 | `resenha-app-icon-32.png` |
| 32 | 2x | 64 | `resenha-app-icon-64.png` |
| 128 | 1x | 128 | `resenha-app-icon-128.png` |
| 128 | 2x | 256 | `resenha-app-icon-256.png` |
| 256 | 2x | 512 | `resenha-app-icon-512.png` |
| 512 | 2x | 1024 | `resenha-app-icon-1024.png` |

The same 32, 256 and 512 px files also cover the 32@1x, 256@1x and 512@1x
slots in the asset catalog.

## Logo system

- `mark/`: symbol alone, source SVG plus ink and light 1024 px PNGs.
- `lockup/`: symbol + wordmark, source SVG plus ink and light 2400 px PNGs.
- Ink: `#101114`; light: `#F7F6F2`; accent: `#6EA397`; paper: `#F0EBDD`.

Use the app icon for stores and launch surfaces, the mark at compact sizes and
the lockup when “Resenha” is not already visible in adjacent text.
